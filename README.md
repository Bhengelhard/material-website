# Material

The Material website. Static HTML, CSS, and JavaScript with no build step.

- `index.html` agency home
- `studio/` venture studio
- `team/` team
- `404.html` not found page
- `styles.css`, `site.js`, `images/`
- `build/` build with us form

Run locally: `python3 -m http.server 8765` in this folder, then open http://localhost:8765/.

Deployed on Vercel. Production is the `main` branch; every push to `main` goes live at materialbuilt.com.
